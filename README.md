# utils

A collection of standalone scripts and notebooks for Databricks, PySpark, Azure, and general Python tasks. Each folder is independent — pick what you need.

## Contents

- **DatabricksAI/** — Building, testing, and deploying Databricks AI agents; Unity Catalog function setup; a basic chatbot notebook.
- **DatabricksParallelRun/** — Example of running multiple Databricks tasks in parallel via a master script.
- **DatabricksRestApi/** — Fetching job details through the Databricks REST API.
- **SCD-Implementation/** — Slowly Changing Dimension (Type 1 and Type 2) implementations.
- **azure_blob_storage_read/** — Reading files from Azure Blob Storage.
- **azure_cost/** — Querying Azure cost data via API.
- **databricks_tables_version_rowcount_snapshot/** — Snapshotting table versions and row counts across a catalog.
- **get_youtube_playlist_videos_name/** — Fetching video names from a YouTube playlist.
- **mssql_ddl_creator/** — Generating MSSQL DDL from sample input.
- **pyspark_delta_upsert/** — Upserting into Delta tables with PySpark.
- **pyspark_drop_duplicates/** — Different ways to drop duplicates in PySpark.
- **pyspark_explore_flattern/** — Automatically exploding/flattening nested PySpark structures.
- **python_bulk_download_whl_files/** — Bulk-downloading Python wheel files.
- **python_computer_test/** — CPU/memory stress-testing scripts.
- **send_mail/** — Sending emails from Python.
- **spark_cluster_monitoring/** — Monitoring Spark cluster/node status.
